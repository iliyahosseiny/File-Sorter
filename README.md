# File Sorter v1.0 (release)

A simple file sorting tool built with Node.js.

## Project Description

I created this project for personal use to organize my Downloads folder, which had more than 1000 mixed files.
The program automatically sorts files into categories like Videos, Images, Documents, Music, Compressed files, and more.

## Project Goal

The main goal of this project was to learn and practice:
- Node.js file system operations (`fs`)
- Working with paths (`path`)
- Handling user input
- Asynchronous programming
- Building a practical command-line tool

## Features

- Automatic file categorization based on file extensions
- Creates folders automatically
- Prevents filename conflicts
- Supports custom categories
- Generates sorting logs

## Usage

Run:

```bash
node index.js

(Enter the path of the folder you want to sort.
Example: /home/iliya/Downloads)
